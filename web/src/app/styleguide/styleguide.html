Stack sections

The dashboard's list view, built from the same pieces. Each Compose stack is a tm-section with a tm-container-table. All tables share fixed column widths, so one sticky tm-column-bar labels them all (scroll to see it stick); each table keeps a sm:sr-only header for screen readers. Rows are tr.tm-row-link: the name is a stretched link, so the whole row is clickable (here it stays on this page). Below 640px, tm-table-stack stacks each row: name first, then version and update. Rows that are up to date are toned down automatically (data-current), so the ones with an update stand out; with dimQuiet (the dashboard sets it everywhere) quiet rows (up to date, snoozed, ignored) also fade as a whole (data-dimmed, 60%, full again on hover or keyboard focus; sonarr below). With showStack the stack name sits before the status, for lists that aren't grouped by stack. Stacks with nothing to do go together into one collapsed, muted "Up to date" section, each a level 3 sub-section (smaller h3 heading).

Reviewed & snoozed

An update the user has dealt with (review on the container). Reviewed: the badges fade and a quiet "Reviewed" marker (check icon + word) joins them; the row stays in place. Snoozed: the badges fade, the version cell says "until 3 Nov" or "until newer than v2.0.1", and the row or tile is toned down like an up-to-date one. A channel tag, or a floating tag without a version, is reviewed and snoozed against the build (its registry digest): "Reviewed this build", "until a new build", never the digest itself. Snoozed containers move to a collapsed "Snoozed" section above "Ignored". Neither state has a colour of its own: it is not a risk.

Tooltips

[tmTooltip] replaces the native title. It appears after a short hover or on keyboard focus, and on touch a tap toggles it (a tap elsewhere closes it). It closes on Escape, only one is open at a time, and the pointer can move onto it. A newline in the text gives a second line. Empty text shows nothing.

Callouts & release notes

Callouts explain why something is missing and what to do. Release notes are sanitised markdown (images become "Image: alt" links); lines the breaking-change analysis flagged get a highlighter in the level's colour, the words that triggered it a dotted underline, and hovering a line says why. Long notes sit in a tm-clamp; with marks its button counts the flagged lines it hides.

The repository has no releases and no CHANGELOG.md. Set TIDEMARK_GITHUB_TOKEN to raise the limit. DB_URL is now DATABASE_URL. A callout without a heading.
