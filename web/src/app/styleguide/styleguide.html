Stack sections

The dashboard's list view, built from the same pieces. Each Compose stack is a tm-section with a tm-container-table. All tables share fixed column widths, so one sticky tm-column-bar labels them all (scroll to see it stick); each table keeps a sm:sr-only header for screen readers. Rows are tr.tm-row-link: the name is a stretched link, so the whole row is clickable (here it stays on this page). Below 640px, tm-table-stack stacks each row: name first, then version and update.
