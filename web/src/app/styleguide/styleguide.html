Stack sections

The dashboard's list view, built from the same pieces. Each Compose stack is a tm-section with a tm-container-table. All tables share fixed column widths, so one sticky tm-column-bar labels them all (scroll to see it stick); each table keeps a sm:sr-only header for screen readers. Rows are tr.tm-row-link: the name is a stretched link, so the whole row is clickable (here it stays on this page). Below 640px, tm-table-stack stacks each row: name first, then version and update. Rows that are up to date are toned down automatically (data-current), so the ones with an update stand out. With showStack the stack name sits before the status, for lists that aren't grouped by stack.

Tooltips

[tmTooltip] replaces the native title. It appears after a short hover or on keyboard focus, closes on Escape, and the pointer can move onto it. A newline in the text gives a second line. Empty text shows nothing.

Accent colour only. Override --tm-gauge-line and --tm-gauge-floor to move the line and the lowest water. The waves stop under reduced motion.
